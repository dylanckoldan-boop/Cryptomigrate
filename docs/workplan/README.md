# Project workplan

`AES_Migration_Project_Workplan.docx` is the SDLC project workplan and Business Requirements Document this repository implements: objectives, scope, stakeholders, functional and non-functional requirements (FR/NFR), the seven-phase workplan, WBS, RACI, risk register and Key Management Plan.

See [../SDLC_MAPPING.md](../SDLC_MAPPING.md) for how each phase maps to commands and gates, and [../TRACEABILITY_MATRIX.md](../TRACEABILITY_MATRIX.md) for requirement-level traceability. Fill in the bracketed placeholders for your organization, as in `migration.yaml`.
